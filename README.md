# 紅派？白派？ いちご狩り予約LP｜ベリーの丘ファーム

架空のいちご農園「ベリーの丘ファーム」の、春休み限定いちご狩りの予約LPです。
紅ほっぺ（赤）と淡雪（白）の「紅派？白派？」食べ比べをコンセプトにしています。

**サイト**：https://huruuuuuugi.github.io/strawberry-picking-lp/

> ※ベリーの丘ファームは架空の農園です。料金・期間・空き状況・地図・住所などはすべてイメージで、実際の予約はできません。

## 概要

| 項目 | 内容 |
|---|---|
| ペルソナ | 春休みに友達と出かけ先を探している、女子大学生3〜4人のグループ |
| 目的 | グループでのLINE予約 |
| 表示 | スマホ向け（デザインは幅390px）。PCでは中央に表示 |
| デザイン | Figma |

## 使用技術

- HTML / CSS / JavaScript（ライブラリなし）
- CSSはBEM、モバイルファースト、色・余白はCSS変数（デザイントークン）で管理
- JavaScriptで実装した機能
  - 品種紹介のタブ切り替え（キーボードの←→にも対応）
  - 空き状況カレンダー（2週間ずつ表示）
  - スクロールで要素が登場するアニメーション（IntersectionObserver）
  - よくある質問のなめらかな開閉（details / summary ＋ Web Animations API）

## 工夫したこと

- FVの「紅派はこっち→」「白派はこっち→」を押すと、その品種のタブが開いた状態で紹介へ移動する
- 吹き出しと丸い写真を左・右・左と交互に置き、スクロールにリズムを出した
- 料金・アクセス・FAQなど「比べる・確かめる」情報は動かさず、ポップな動きは楽しさを伝える場所に絞った
- `prefers-reduced-motion`（動きを減らす設定）では、アニメーションを止める
- JavaScriptが動かなくても、内容がすべて読める
- 写真はJPEGにして、表示幅に合わせたサイズにした（合計 約13.5MB → 約1.4MB）
